# Contributing

1. Open an issue for new dialects or public API changes.
2. Create a focused branch from the current default branch.
3. Run `npm ci` and `npm run check` on Node.js 18 or newer.
4. Base protocol behavior on current primary provider documentation and link it in the change.
5. Add valid fixtures plus truncation, reordering, duplication, and error mutations.
6. Update the README and changelog for behavioral changes.

Never submit real prompts, generated private content, API keys, request headers, or customer event logs. Contributions must be original or appropriately licensed and are distributed under the MIT license.
